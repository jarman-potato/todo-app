# todo-app

A simple React-based Todo application with priority management.

## Features

- ✨ Add new tasks
- 🎯 Set task priority (High/Medium/Low)
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 📊 Auto-sort tasks by priority
- 🎨 Color-coded priority indicators
- 📱 Clean and responsive UI

## New Features (v1.1)

### Priority Management
- Assign priorities when creating tasks
- Change priority of existing tasks with dropdown
- Tasks are automatically sorted by priority (High → Medium → Low)
- Color-coded visual indicators:
  - 🔴 **High**: Red (Urgent tasks)
  - 🟡 **Medium**: Yellow (Regular tasks)
  - 🟢 **Low**: Green (Nice-to-have tasks)

## Getting Started

```bash
npm install
npm start
```

## Usage

1. Enter a task name in the input field
2. Select a priority level from the dropdown (default: Medium)
3. Click "Add" button
4. Click checkbox to mark tasks as complete
5. Use the priority dropdown on each task to change its priority
6. Click "×" to delete a task

Tasks will be automatically sorted with high-priority tasks appearing first!
